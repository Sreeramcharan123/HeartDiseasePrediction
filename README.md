 ❤️ Heart Disease Prediction System
 Project Overview

This project is a web-based application that predicts the likelihood of heart disease using Machine Learning. It helps users understand their health condition based on medical parameters.

---

🚀 Features

* Predicts heart disease using ML model
* User-friendly web interface
* Fast and accurate results
* Built using Python & Flask

---
🛠️ Technologies Used

* Python
* Flask
* Scikit-learn
* HTML, CSS
* Pandas, NumPy

---

 📂 Project Structure

* app.py → Main application
* train_model.py → Model training
* heart_model.pkl → Trained model
* templates/ → HTML files
* static/ → CSS files

---
 ▶️ How to Run

1. Install dependencies:
   pip install -r requirements.txt

2. Run the app:
   python app.py

3. Open in browser:
   http://127.0.0.1:5000/
